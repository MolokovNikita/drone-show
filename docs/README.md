# Документация системы управления световыми шоу дронов

Эта папка содержит полную техническую документацию системы.

## 📋 Содержание документации

### 1. [Техническая спецификация](./technical_specification.md)
Полное техническое задание с описанием:
- Функциональных и нефункциональных требований
- Архитектуры системы
- Структуры базы данных
- API спецификации
- Требований к безопасности

### 2. [ER-диаграмма базы данных](./erd.mmd)
Диаграмма связей между таблицами базы данных в формате Mermaid.
Можно просмотреть в любом Markdown редакторе или на GitHub.

### 3. [Архитектура системы](./system_architecture.md)
Диаграммы архитектуры:
- Общая архитектура (System Context)
- Компонентная архитектура (Container Diagram)
- Слоистая архитектура (Layered Architecture)
- Поток данных (Data Flow Diagram)
- Сетевая архитектура (Network Architecture)

### 4. [Диаграммы последовательности](./sequence_diagrams.md)
Детальные диаграммы последовательности для основных процессов:
- Аутентификация и авторизация
- Получение телеметрии в реальном времени
- Создание шоу через AI генератор
- Назначение дронов на шоу
- Выполнение шоу с мониторингом
- Техническое обслуживание дрона
- Создание хореографии

### 5. [Use Case диаграммы](./use_cases.md)
Диаграммы вариантов использования:
- Общая Use Case диаграмма
- Управление дронами
- Планирование и выполнение шоу
- Мониторинг и алерты
- Техническое обслуживание

### 6. [BPMN процессы](./bpmn_processes.md)
Бизнес-процессы в нотации BPMN:
- Создание и планирование шоу
- Выполнение шоу
- Техническое обслуживание дрона
- Обработка телеметрии и генерация алертов
- Создание хореографии
- Аутентификация и авторизация

### 7. [Промпты для Miro](./miro_prompt.md)
Готовые промпты для создания диаграмм в Miro или других инструментах визуализации.

## 🎯 Как использовать документацию

### Для разработчиков
1. Начните с [технической спецификации](./technical_specification.md) для понимания требований
2. Изучите [архитектуру системы](./system_architecture.md) для понимания структуры
3. Используйте [диаграммы последовательности](./sequence_diagrams.md) при реализации функций
4. Сверяйтесь с [ER-диаграммой](./erd.mmd) при работе с базой данных

### Для менеджеров проекта
1. [Use Case диаграммы](./use_cases.md) показывают функциональность системы
2. [BPMN процессы](./bpmn_processes.md) описывают бизнес-процессы
3. [Техническая спецификация](./technical_specification.md) содержит все требования

### Для новых участников команды
1. Прочитайте [техническую спецификацию](./technical_specification.md)
2. Изучите [архитектуру системы](./system_architecture.md)
3. Просмотрите [диаграммы последовательности](./sequence_diagrams.md) для понимания потоков
4. Ознакомьтесь с [ER-диаграммой](./erd.mmd) для понимания структуры данных

## 📊 Просмотр диаграмм

Все диаграммы созданы в формате **Mermaid**, который поддерживается:
- GitHub (автоматически рендерится)
- GitLab (автоматически рендерится)
- VS Code (с расширением Mermaid Preview)
- Онлайн редакторы: [Mermaid Live Editor](https://mermaid.live)

## 🔄 Обновление документации

При изменении системы обновите соответствующие диаграммы:
- Изменения в БД → обновите [ER-диаграмму](./erd.mmd)
- Новые процессы → добавьте в [BPMN процессы](./bpmn_processes.md)
- Изменения архитектуры → обновите [архитектуру системы](./system_architecture.md)
- Новые функции → обновите [Use Case диаграммы](./use_cases.md)
